# Batch Spec: U12-MODELGOV

## 目的

模型设置全面改造（多轮需求合批）：厂商中心详情页（厂商头总开关/⋯菜单/API 格式
自绘下拉/Key 显隐/模型行插头连接测试+铅笔编辑+启用开关）；模型元数据内置 Rust
meta 模块（models.dev 启动同步进 SQLite，meta_* 命令，废弃独立 Python 服务方案）；
厂商 logo 换本地 lobehub SVG 资产（providerKey 别名表 + 名称归一化 + 兜底色块）；
添加厂商网格收敛中国厂商+头部外国+OpenRouter；API Key 按厂商名分存 keyring
（vendor:{name}，read_llm_key 厂商优先回落全局）；可用性一等状态
verified_vendors（连接测试通过才进名单：左栏绿点/聊天下拉过滤/插头常绿同源；
key 覆盖/清除、URL/协议变更由 prune_verified_vendors 剔除）；厂商页保存配置
联动自动连接测试；删 fetch_provider_models 与「从厂商获取」；删除厂商/模型
即时落盘；下拉浮层 nm-popover（修 nm-outset hover 半透明透出下方内容）；
Anthropic 标签去 /v1/messages + anthropic_messages_url 容忍误粘端点路径。

## 审计处置记录（提交前全量 diff 审查，1P0/6P1/8P2）

- **P0 修**：probe_connection anthropic 分支补 /v1 前缀（否则 Anthropic 厂商
  探测 404，永远进不了 verified_vendors）+ 集成测试补 base 不带 /v1 用例。
- **P1 修 5**：prune 签名改（协议,URL）BTreeSet（顺序变化不误剔、换协议必剔）；
  onTested 改 await loadConfig 后再广播（防旧 state 整写擦掉刚落盘验证态）；
  模型库空库（length 0）也回退内置预设网格且保留「更新模型库」入口；厂商降级
  key 文件名加 FNV 短散列（防净化撞名/大小写不敏感 FS 互覆）；vendorMetaOf
  两段式匹配（精确优先归一化，防 minimax 系兄弟厂商误抢）。
- **P2 修 2**：模型页保存失败补可见错误（botError 渲染进厂商页保存行）；
  ProviderLogo 死分支（slice 不会 undefined）。
- **P2 登记不修**：每模型推理参数（temperature/top_p/max_tokens/system_prompt）
  已持久化但请求装配未消费（下一批接线）；存量带 vendor 条目升级后 verified
  为空需逐厂商重测一次（无迁移，设置页注释引导）；meta 同步只增不删（上游
  下架行残留，可接受）；bot_set_config 先写 key 后写配置的孤儿 keyring 窗口
  （毫秒级，无清除入口，登记）；旧全局 key 条目保留作回落（read_llm_key 注释
  已标）。

## 红线核对

- 聊天主循环/Planner/摘要只换取 key 入口（read_llm_key 等价回落），请求装配零改动；
  双窗口/主题/看板零改动；tools/权限/进化模块零改动。
- key 本体永不落配置文件（vendor key 走 keyring 独立条目；config 序列化无 key 字段）。
- 342 个 SVG 资产由 scripts/sync-lobe-icons.mjs 从 @lobehub/icons-static-svg
  （精确锁版 1.95.1）同步，可复现。
