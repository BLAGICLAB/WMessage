# Batch Spec: C5-AP-06

## 目的

C5-AP-06 独立批：`broadcast` 内 `atomic_write` 失败从静默吞改为 log 可见，family = error-visible-non-blocking。

## 人类可读摘要

- family: error-visible-non-blocking
- 覆盖 findings: 1
- 预估 diff: 1 file / +3/-1 lines
- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 5

## 红线

- family 一致性：本批只含 error-visible-non-blocking，不混入 error-not-propagated
- 0 FP / 0 family 异质
- `broadcast -> ()` 不允许 `?`（Rust 编译层事实）；改签名超预算，本批不做

## Stop 条件（遇到即停，报 reviewer）

- `atomic_write` 返回类型变化（非 `Result<(), String>`）
- `eprintln!` 前缀 `[event_hub]` 与仓库惯例不符且无合理解释
- OCR 新 high 非同根因
