# BUG-003 — `items after test module`(测试模块位置)

## 位置
- `src-tauri/src/api_auth.rs`:175 — `pub fn verify_bearer` 在 `#[cfg(test)] mod tests`(行 126)之后
- `src-tauri/src/bot/config/mod.rs`:645 — `fn _unused_marker` 在 `#[cfg(test)] mod tests`(行 76)之后

## 严重度
**S3**(design — 文件组织,无功能影响)

## 类别
clippy `items_after_test_module`

## 复现步骤
```bash
cd src-tauri
cargo clippy --tests -- -W clippy::items_after_test_module 2>&1 | rg "items after a test module"
```
输出(修复前):
```
warning: items after a test module
  --> src/api_auth.rs:127:1
  --> src/bot/config/mod.rs:77:1
```

## 根因
Rust 惯例:`#[cfg(test)] mod tests` 应放文件底部。`api_auth.rs` 的 `verify_bearer` 和 `bot/config/mod.rs` 的 `_unused_marker` 都被放在 test module 之后,违反惯例 — IDE/clippy/读代码者按惯例向下滚动时找不到这两个函数。

## 修复方案
把 `verify_bearer`(含 doc comment)和 `_unused_marker`(含上下文注释)整体搬到对应文件的 `mod tests` 之前。位置不变,函数体不动,仅交换相邻关系。

## 修复文件清单
- `src-tauri/src/api_auth.rs` — +9 / -9(纯位置搬移,函数体不动)
- `src-tauri/src/bot/config/mod.rs` — +8 / -8(纯位置搬移,函数体不动)

合计 2 文件,2 项位置调整,净 0 行(实际 +17/-17 是含 doc comment 的成块搬移)。
