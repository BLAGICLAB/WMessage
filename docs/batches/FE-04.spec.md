## 逐条处置（原文均已核）

**FP ① SubtaskRow.tsx:27-36（high → FP）**：finding 称 `onCommit` 闭包捕获旧 `sub.text`（stale closure）。**核后**：`useInlineEdit`（src/components/useInlineEdit.ts）每渲染重建 commit/onBlur 闭包并调**当次渲染**的 props（无 useCallback/useRef 缓存旧回调）；SubtaskRow 未 memo 化，父 TodoCard 无 memo 边界——`sub.text` 变必随父重渲染，闭包永远最新，无 stale 窗。前提错误，零代码处置（reviewer pass 后才可标）。

**实修 ② SubtaskRow.tsx:48-57（high）**：`readOnly` flip 到 true 时已挂载的编辑 `<input>` 无 readOnly/disabled，用户可继续输入甚至 onCommit；且无 effect 在 readOnly 变 true 时退出编辑态。
**修法**：`useEffect(() => { if (readOnly) setEditing(false); }, [readOnly])` + 编辑中 input 加 `readOnly={readOnly}` 属性（flip 到 effect 生效间的空档兜底）。

**实修 ③ WorkspacePage.tsx:80-84（high）**：`persist`/`handleSortEnd` emit `workspace-changed`，本组件 listener 的 reload 可在 `setItems(next)` 与 `upsertWorkspaceItems` resolve 之间落地，用旧 DB 内容冲掉乐观态。
**修法**：写并发守卫——`writeInFlight = useRef(0)` + `reloadQueued = useRef(false)`；reload 移到组件级；listener 改 guardedReload（写在飞则置 queued 直接返回）；persist 与 handleSortEnd 的写各包 `writeInFlight.current++` / `finally` 里 `--` 且归零时若 queued 则补一次 reload。**persist 不加 catch**（:144 silent persistence 是 medium 非本簇，维持现状）。

**实修 ④ WorkspacePage.tsx:99-109（high）**：`changed.forEach(it => it.updatedAt = now)` 就地突变共享 state 对象（assignInsertOrder 已核不突变——storage.ts:160 起只给变化索引产副本）。
**修法**：先算 `changedIds = new Set(next0.filter(it => JSON.stringify(it) !== JSON.stringify(prevMap.get(it.id))).map(it => it.id))`，再 `next = next0.map(it => changedIds.has(it.id) ? { ...it, updatedAt: now } : it)`，setItems(next)，写 `next.filter(it => changedIds.has(it.id))`（带 writeInFlight 跟踪，`void upsert...finally(endWrite)`，emit 顺序不变）。

**实修 ⑤ MarkdownText.tsx:21（high）**：`String(children ?? "")` 对数组 children 以 `,` join 产出 "foo,bar"，可把无害代码段误判为 URL/路径路由进 openTarget。
**修法**：仅 `typeof children === "string"` 或全 string 数组（`join("")`）才参与链接化，否则原样 `<code>`；顺手把局部变量 `text` 改名 `linkText`（消 shadow prop，同行区，连同 low finding 一并处置）。

**实修 ⑥ MarkdownText.tsx:34-42（high）**：可点 `<code>` 无 role/tabIndex/键盘语义，屏幕阅读器不播报。
**修法**：URL/路径行内代码渲染改 `<a href={linkText}>` + `onClick={(e) => { e.preventDefault(); openTarget(linkText); }}`（样式 className 照抄原 code 的），与 a renderer 同形态，键盘可聚焦。
