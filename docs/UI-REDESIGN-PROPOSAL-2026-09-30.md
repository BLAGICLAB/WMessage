# UI 改造方案 — 对齐「现代 Agent 桌面端」设计语言

> 2026-09-30 · 应老板需求出方案（参考截图：ZCode 风格深色三栏布局）。
> **本文档只出方案不动代码**；拍板后按期分批实施，走既有 spec/门禁流程。

## 0. 一句话结论

把现在的「新拟态凸起卡片风」整体换成截图那种「扁平分层 + 左导航 + 会话式聊天」
的现代深色设计。分四期落地，每期独立可验收可回滚；其中聊天面板那期与已登记的
B5-2/3（ChatPanel 拆分）**合并执行**，避免同一文件改两遍。

## 1. 截图设计语言拆解（对齐目标）

| 维度 | 截图的做法 | wmessage 现状 | 差距 |
|---|---|---|---|
| 表面体系 | 三层灰阶：页面底（近黑）→ 面板（+1 档）→ 悬浮卡（+2 档），靠**色阶+1px 边框**分层 | 新拟态双阴影（凸起/凹陷），靠阴影造型 | 核心差距：材质体系整体不同 |
| 布局骨架 | 左窄导航栏（新建/搜索/自动化 + 项目→会话栈，相对时间）+ 中间对话主列 + 右侧标签面板（辅助对话/审查/终端/浏览器） | 主窗口 = 看板三列全屏 + 顶部工具条；聊天在挂件/主窗面板 | 信息架构级差距 |
| 消息形态 | 助手回复 = 无边框富文本卡片（markdown + 内嵌工具卡片 + hash pill 徽章 + 折叠「进程 2/2」浮卡 + diff 摘要条「+149 -4 ↩撤销」）；用户消息 = 右对齐浅底气泡 | 气泡流（用户/助手气泡 + 折叠工具行） | 表现层差距 |
| 输入区 | 大圆角输入卡：placeholder 灰字、左下 + 附件、**权限选择（完全访问▾）**、**模型选择器**、推理档选择、圆形上箭头发送 | 单行输入 + 简单按钮 | 组件级差距 |
| 图标 | 线性 icon（1.5px stroke），克制 | 混用 emoji（🗑✎）+ 少量 svg | 需引入统一图标库 |
| 色彩 | 深色为主；强调色极克制（成功绿、发送钮、pill 灰） | 低饱和蓝紫灰品牌色 | 需收敛强调色使用面 |
| 细节 | commit hash 用 mono 字体 pill 徽章；相对时间（刚刚/12小时/1天）；空态有标题+说明+行动 | 时间戳直显 | 小组件级 |

## 2. 与现有架构的衔接（不推倒重来）

- **主题机制保留**：`ui/main.css` 已有 `:root`/`.dark` 双套 CSS vars + 三态主题
  （浅/深/跟随系统，双窗口 storage 同步）——改造 = **换 token 值 + 换材质类**，
  主题切换机制、双窗口同步原样复用。截图是深色优先，但浅色主题同步重做（不砍）。
- **`nm-*` 类做兼容映射**：全仓 ~28 处/文件量级的 nm-card/nm-btn 使用点，在
  main.css 里把 `.nm-card` 等类**重新实现**为新材质（同名换实现），
  上层组件基本不动——这是低风险换肤的关键杠杆。
- **不动后端/数据层/双窗口架构**：Tauri 双窗口、事件桥、SQLite 全部不动。
- **挂件窗口（WidgetApp）**：跟 token 走自动换肤，布局（任务/工作区/聊天三视图）
  不动，二期只做细节对齐。

## 3. 分期方案（每期一个 spec 批，独立可验收）

### U1 — 设计 token 与材质体系（换肤地基，S-M）

- 重写 `ui/main.css` token：三层表面（--bg / --surface / --surface-raised）、
  1px 边框（--edge 已有，调整语义）、圆角梯度（--r-sm 8 / --r-md 12 / --r-lg 16）、
  阴影从「双阴影拟态」改为「单层柔和投影 + 边框」、字号阶梯（13/14/15/16）、
  强调色收敛（success 绿 + 一种品牌强调）。
- `.nm-card / .nm-btn / .nm-inset / .nm-outset ...` 全部同名重实现为扁平分层材质
  ——**全仓组件零改动换肤**（this is the trick）。
- 引入 `lucide-react` 图标库（线性 icon，与截图一致；唯一新依赖），先铺
  IconButton 基础件，替换 emoji 图标（🗑✎ 等）分批进行。
- 验收：三态主题各截 6 个主要页面比对；全部测试绿（快照类断言不受影响——
  测试按语义查不按样式查）；deep/light 双主题人工过一遍。

### U2 — 主窗口骨架升级（信息架构，M）

- App.tsx（722 行）加**左侧导航栏**：新建任务（⌘N）/ 搜索（⌘K）/ 视图切换
  （看板/归档/回收站/工作区）+ 底部设置入口；替代现顶部工具条的部分职能。
- 主内容区按所选视图渲染（看板保持三列拖拽核心交互不动）。
- ⌘K 搜索浮层（任务/会话聚合搜索，先做任务+会话标题匹配）。
- 验收：键盘流 ⌘N/⌘K 可用；看板拖拽回归；双窗口同步回归。

### U3 — ChatPanel 重构（对齐截图的核心一役，M-L）⚠️ 与 B5-2/3 合并

- **先拆后换**：1851 行拆为 会话列表 / 消息列表 / 输入区 / hooks 四文件
  （正是 B5-2/3 登记项，一次施工两得），补齐 MsgBubble + React.memo 流式性能项。
- 会话列表：左侧会话栈（标题 + 相对时间），对齐截图「项目→会话」层级。
- 消息形态改造：
  - 助手消息 → 无边框富文本卡；工具调用 = pill 徽章行（mono 字体）+ 可折叠
    「进程 N/M」状态浮卡（勾选逐项，完成后灰化划线——对齐截图）；
  - 文件/产物变更 → 「N 个文件已更改 +X -Y」摘要条（diff 汇总已有数据可接）；
  - 用户消息 → 右对齐浅底气泡。
- 输入区 → 大圆角输入卡：附件（+）、模型选择器（读 bot-config 模型列表）、
  **权限模式显示（ask/yolo/strict，读配置）**、圆形发送钮；斜杠命令浮层保留。
- oxlint 存量 32 warn 顺手清零（登记项）。
- 验收：流式性能（memo 前后对比）；全部 ChatPanel 测试迁移绿；视觉比对截图。

### U4 — 设置页 / 挂件 / 细节打磨（S-M）

- SettingsPage 各面板换新材质（U1 自动换肤打底，此处调间距/分组/空态）；
- 挂件窗口细节对齐（圆角/边框/字号）；
- 空态统一组件（EmptyState：标题+说明+行动按钮，对齐截图「打开标签页」空态）；
- 动效克制清单（面板滑入 150ms、按钮 100ms、无弹跳）；
- EvolutionPanel / ConfirmMap / ArtifactBatchDialog 等次级面板统一过一遍。

## 4. 拍板项（开工前需要老板定）

1. **主窗口信息架构**：A = 看板仍是主视图、只加左导航（推荐，改动可控）；
   B = 更激进地改为「会话优先」（像截图那样对话是主列、看板收进导航）——
   改动大且偏离看板产品定位，除非老板想往对话助手形态转。
2. **深浅主题**：默认深色（截图观感）、浅色同步重做保留可切（推荐）；还是仅深色。
3. **图标库**：引入 lucide-react（推荐，与截图一致、MIT、tree-shake）；还是
   继续手写 svg 不加依赖。
4. **实施节奏**：U1→U4 顺序各一批（推荐）；还是 U1+U2 合批先看整体观感。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| nm-* 同名重实现可能漏掉个别直接写样式的组件 | U1 验收逐页人工过；Tailwind 类里引用 vars 的地方不受影响 |
| ChatPanel 拆分+换肤一次施工量大 | U3 拆成「先拆（行为等价，测试迁移绿）→ 再换肤（纯表现）」两步提交，可分别回滚 |
| 双窗口主题同步回归 | 主题机制不动，U1/U3 各跑一次双窗口回归清单 |
| 测试按 class/文案查的断言被改名打断 | 改名只动 css 类实现不动类名；测试断言扫一遍（此前经验：按语义查） |
| 新依赖 lucide-react 体积 | tree-shake 后单个 icon ~1KB，knip 门禁盯死未用项 |

## 6. 工作量粗估

U1：1 批（S-M）· U2：1 批（M）· U3：1–2 批（M-L，含 B5-2/3 合并）· U4：1 批（S-M）。
总计 4–5 个批次，每批走既有流程（实现 → 测试 → ocr 复审 → spec → 门禁提交）。
