## 4. G3-GRAPH 图谱核心（Sigma.js 渲染）

- [ ] ⭐ **导航**：左栏出现「图谱」（工作流之下），点击进入；其余栏目不变
- [ ] ⭐ **本人视图**：只有本人任务时 → 画布出现任务节点（孤立点）；工作流卡聚在
      hub 节点周围，依赖连线带箭头指向下游
- [ ] ⭐ **部门视图（导入演示数据后）**：统计条变 `N 任务 · M 依赖 · K 工作流 · 3 成员`；
      顶部「按成员」着色 → 本人/张三/李四三色区分（本人品牌色，外来紫/橙系）
- [ ] ⭐ **成员过滤**：点「张三」chip → 只剩他的子图；点「李四」同理；重置恢复
- [ ] **Obsidian 交互**：hover 节点 → 邻接子图亮、其余淡出变小变灰；空白拖拽平移；
      滚轮以指针为锚缩放（0.15~4 夹紧）；节点拖拽固定位置（松手后 FA2 继续在其周围收敛）
- [ ] ⭐ **详情面板**：点节点 → 右侧显示标题/状态/归属/标签/note；本人卡有「在看板打开」
      （外来卡只读、没有该按钮）；工作流卡有「打开工作流」
- [ ] **hub 跳转**：双击「周报流水线」hub → 切到工作流视图
- [ ] **过滤器**：状态三开关 / 完成年份（演示数据含 2025/2026）/ 标签 / 工作流多选 /
      孤立节点开关 / 重置——全部联动统计条
- [ ] **搜索**：输入「周报」→ 命中节点描边高亮 + 强制显示标签
- [ ] **空态**：无任务 → 「暂无任务」引导；过滤器全关 → 「当前过滤器下没有节点」
- [ ] **归档在图内**：归档卡（done 色、淡化、常态无标签）出现在图谱，回收站卡**不**出现
- [ ] **worker 物理确认（Windows 重点）**：进入图谱后布局有「展开→收敛」动画 =
      FA2 worker 拉起成功；完全静定 = 收敛自动停机已生效（CPU 回落）；
      若 Windows 上画面永为一坨不动点且无动画 → 查 CSP worker-src（G3-S3）

## 7. 性能边界（G3-SIGMA 后的新口径）

- [ ] ⭐ **千级档**（导入演示数据 + 本人任务，约 1.3k 节点）：过滤点击无可感延迟

- [ ] **万级档**（可选，浏览器 harness `gui-test-screenshots/graph-demo.html?stress=10000`
      或等真实数据积累）：点击仍瞬时（实测 0.5ms）；~30s 收敛后自动停机

- [ ] **离开释放**：切出图谱页再进，无内存阶梯上涨（worker kill + 矩阵回收）
