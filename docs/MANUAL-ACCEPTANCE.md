## 一、主窗口看板

- [x] 启动应用：看板三列「待办/今日/完成」正常显示，种子任务存在
- [x] 新建任务：点「+ 新建任务」→ 卡片出现在待办列顶部 → 标题自动进入编辑态 → 输入标题回车保存
- [x] 空标题处理：清空标题后回车 → 回退原标题，不产生空卡
- [x] 卡片内编辑：点标题进入编辑（单击）、Esc 取消
- [x] 备注：+ 备注 → 输入 → 回车保存；点击已有备注再编辑；备注显示在标题下小字
- [x] 标签：+ 标签 → 输入回车可连加；× 移除标签；标签芯片显示
- [x] 子任务：+ 添加子任务 → 多条添加；勾选/取消勾选；进度 x/y；× 删除子任务
- [x] 截止时间：+ 截止时间 → datetime-local 输入（完整输入即存，无确认键）→ 显示「截止 MM-DD HH:mm」；× 移除；**今日规则**：日期为今天 → 卡片自动进「今日」列
- [x] 截止编辑器防御：输入不完整/非法值（如 2026-02-31、25:99）**不写库**，blur 回退已提交值，不产生坏数据；旧数据 date-only 与带时间两种均正常显示
- [x] 文件绑定：**多文件**。📎 绑定文件（可多选，**上限 10 个**）→ 卡片显示 chip 列表（basename + 单独 × 移除）；📁 绑定文件夹（**仍单选**，已绑文件夹的任务弹提示「已绑文件夹」不加不替换）
- [x] 文件操作：📂 打开文件（多文件任务弹列表选一个）/ 📋 复制文件+标题（多文件复制全部，命名 `{title}-{basename}`，单文件行为不变）；× 解绑（多 chip 各自独立）
- [ ] 多文件上限：尝试添加第 11 个文件时被截断（`bind_files` 最多 10 个），并写警告 audit `truncated=true`
- [ ] 启动迁移：老库任务有 `filePath`/`fileIsDir` 而无 `files` 时，App 启动后自动回填到 `files` 列表（双写过渡，老列保留不删除）
- [ ] 多 chip 超 5 折叠：绑定超过 5 个文件时下方显示「还有 N 个」折叠行
- [ ] 文件夹单选独占：已绑文件夹的任务点 📎 绑文件 → 弹提示不追加不替换；点 📁 绑文件夹同理
- [x] 打勾圆圈：点 ✓ → 卡片进「完成」列（自动记完成时间，显示在 × 与 🗑️ 之间居中「完成 MM-DD HH:mm」）；完成列再点 → **截止日期**是今天 → 回「今日」、否则回「待办」，完成时间删除；× 移除按钮紧贴截止日期
- [x] 折叠开关：标题右侧 ▸/▾ 收起/展开标题以下内容；折叠后标题单行截断（悬停看全文）
- [x] 拖拽手柄：悬停卡片显示 ☰（标题左侧占位，不遮挡）；按住拖到其他列（跨列）；列内排序；拖进「完成」自动记完成时间；拖出「完成」清除
- [x] 拖拽边界：待办拖进**空的**完成列能成功落卡（回归：松手落点 bug）
- [x] 删除：卡片右下 🗑️ → 进回收站
- [x] 卡片结构顺序：标题 → 备注 → 标签 → 子任务 → 文件按钮 → ⏰/🤖 → 截止时间**永远最底**

## 二、今日规则与归档

- [x] 今日规则：新建任务设截止=今天 → 自动进「今日」列；跨零点自动归位（或等 1 分钟观察）
- [x] 自动归档：完成满 7 天的任务自动进归档（新完成的不归档属正常）
- [x] 归档页入口：完成列底部「🗄 已归档 N」→ 归档页
- [x] 归档页：搜索框（标题+备注）；标签计数筛选（点选/取消）；三列网格按 order 从左到右填充；卡片默认折叠
- [x] 归档任务卡**不可拖拽**（无拖拽手柄/排序，仅展示）
- [x] 归档只读：除折叠开关 ▸/▾、绑定文件/文件夹可打开（📂）与复制（📋，多文件复制全部，单文件行为不变，桌面清理迁移后核验）、↩ 恢复外，其余（标题/备注/标签/子任务勾选/截止/🗑️/🤖/⏰/解绑×）一律不可编辑不可点击
- [x] 归档恢复：展开卡片 → 「↩ 恢复」→ 回看板

- [x] 彻底删除：🗑 彻底删除 → 确认后永久删除
- [x] 清空回收站：右上「清空回收站」→ confirm 后全清
- [x] **回收站任务卡只读**（2026-08-17）：除折叠开关 ▸/▾、📂 打开、📋 复制、↩ 恢复、🗑 彻底删除外，其余（标题/备注/标签/子任务勾选/截止/🗑️ 单独删除/🤖/⏰/解绑×）一律不可编辑不可点击（与归档卡同模式）
- [x] **彻底删除绑文件弹窗**（2026-08-17 三选项版 + 21:17 移到废纸篓/回收站）：任务卡绑定了文件/文件夹时点 🗑 彻底删除 → 三选项弹窗（Portal 到 body 跳出 TodoCard transform 包含块 + nm-card）：「任务卡《X》绑定了文件/文件夹《Y》。完整路径：/.../Y。此操作不可撤销。」＋三个按钮：🗑 **全部删除**（红，先 `delete_bound_file` 成功才删任务行，失败 alert 任务行保留可重试）／📄 **保留文件删除**（只删任务卡，本地文件保留）／**取消**（都不删，点 backdrop = 取消）；三按钮均按 `purgeBusy` 防误点；「全部删除」改走 **跨平台 trash crate**（Mac → 废纸篓 / Win → 回收站 / Linux → gio trash），不是物理删除，误删可恢复
- [x] **彻底删除绑文件夹**（2026-08-17 三选项版 + 21:17 trash）：同上，但 `task.fileIsDir` 为 true → 弹窗文案「文件夹」+ Rust 端 `delete_bound_file` 统一走 `trash::delete_all`（不再按 is_dir 分流，crate 内部递归处理）；三选项按钮文案同（按 fileIsDir 自动适配「文件夹/文件」）
- [x] **彻底删除绑多文件**（2026-08-19）：任务卡 `files` 数组有多个文件/夹时点 🗑 → 弹窗列出全部绑定（每个一行：📁/📎 basename + 完整路径），按 fileIsDir 自动适配「文件夹/文件」文案；三选项对全部绑定生效（全部删除走 trash）
- [x] **彻底删除无绑定**：未绑定 files 时点 🗑 → 原两选项 `window.confirm` 「确定彻底删除任务《X》？此操作不可撤销。」（无三选项歧义场景，保持原实现即可）

### 21:42 老板发现并修复「挂件双击唤起主窗口后标题输入框显示旧值」

- **症状**：挂件新建任务并改名为「测试」→ 立即双击标题唤起主窗口 → 主窗口看板那张卡的 input 框显示「**新任务**」（默认值），不是「测试」。挂件自己显示「测试」（正常）
- **根因**：主窗口 `TodoCardView` 的标题草稿用 `useState(task.title)` 取初值；React useState 初值只在 mount 时计算一次，挂件发 `tasks-updated` 后主窗口 `setTasks` 重渲染但 `<SortableTodoCard key={t.id}>` 的 key 不变，TodoCardView 不重挂载 → `draft` 停在第一次渲染时的「新任务」；双击唤起后 `edit-task` 事件 → `setEditingId(id)` → autoEdit 由 false 变 true → useEffect 触发 `setEditing(true)` 但**不**同步 draft → 渲染 `<input value={draft}>` 显示「新任务」
- **挂件没踩的原因**：`TaskCardContent` 的 useEffect 写了 `if (editingTitle) setDraft(task.title)`，会同步草稿
- **修法**（`src/components/TodoCard.tsx`）：用 `prevAutoEdit` ref 锁住「autoEdit 由 false→true 那一瞬」同步 `setDraft(task.title)`，避免 editing 期间因 task.title 进依赖而覆盖用户输入；editing 期间 task.title 不会外部变化（commit 才改，且同时 setEditing(false)），所以 task.title 加进依赖安全
- **关联验收项**：五.「双击唤起后编辑框标题与挂件同步」
- **验证**：tsc + vite build 全过；dev 实例手动跑一遍流程不再复现
