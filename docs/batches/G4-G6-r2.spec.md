## 目的

真机验收反馈：节点一闪而过/画布空白（linLog 回退后仍复现）。定位两个叠加
因素：① 布局坐标空间固定不随任务量缩放，万节点密度爆炸互相挤出视野；
② 布局发散期间视野不跟随，节点冲出初始包围盒后相机拍原地。

## 实现（老板决策：linLog 与自动物理保留，不降级）

- 布局外径 `R_MAX = 30·√N`（√N 缩放 = 面密度恒定），有组扇区内圈 62%
  均匀面密度、无组孤点外环黄金角散布
- followFit：布局期间每 2s 相机跟随膨胀中的包围盒；收敛停机时终态精调
- linLogMode: true 恢复（团簇分离杠杆）；「重新布局」按钮保留

## 验证

IAB harness 1227 档：1268 节点全部在视口内、span ±980 有界、收敛自动停。
FPS 数值留真机验收。
