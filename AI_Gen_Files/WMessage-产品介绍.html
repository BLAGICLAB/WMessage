Skill DSL

让 AI 也能按流程跑

Markdown + YAML frontmatter + 步骤编排 + 可选回滚段。状态机驱动 5 种决策，失败可自动或手动恢复。

5 种状态机决策

每个 step 执行前查询 advance_dsl，根据结果决定下一步走向——Run / Finish / AwaitUser / FailWithRollback / Terminate。FailedButRecoverable 时把已完成摘要注入系统 prompt，让 LLM 接管下一步。

  • Run — 继续执行下一步
  • Finish — 流程成功结束
  • AwaitUser — 暂停等用户输入
  • FailWithRollback — 执行 Rollback 段
  • Terminate — 不接管，安全终止
---
name: weekly-report
version: 1.0
---

## Step 1: 抓取本周数据
web_search({
query: "本周 GitHub 趋势"
})

## Step 2: 生成 Excel
create_excel({
filename: "weekly"
sheets: [{...}]
})

## Rollback
delete_task({id: "${prev.id}"})

FAQ

常见问题

WMessage 是云端 SaaS 还是本地应用？

完全本地。数据存 SQLite，文件操作走本地 fs，仅 AI 对话需要联网调用 LLM。

内置机器人的 API Key 存在哪？

存在系统凭据存储（keyring），不落本地明文文件；设置页填写一次即可。

任务完成后的文件会被自动删除吗？

默认仅「移动归档」，删除动作（delete）默认关闭，需用户显式启用；未归档任务的附件永远不动。

支持哪些平台？

Windows 10/11（NSIS exe + 绿色 zip）、macOS（universal dmg，Intel + Apple Silicon）。Linux 后续评估。

Skill DSL 适合什么场景？

任何需要「固定步骤 + 自动恢复」的 AI 工作流——周报生成、批量文档润色、定期数据抓取等。
