## 2. G1-OWNER 数据基座

- [ ] ⭐ **导出 v2**：设置 → 数据管理 → 导出 → 打开 JSON：
      `version=2`、`profile.personId` 非空、`tasks[].ownerId` 全部 = 本人 pid、`people` 数组存在
- [ ] ⭐ **v1 兼容导入**：导入旧版裸数组导出文件 → 提示导入成功，任务出现在看板
- [ ] ⭐ **多人汇总隔离**：导入同事（张三）的 v2 导出 → **看板/归档/回收站/挂件/⌘K 均不出现**
      张三的任务；`people` 注册表已收录（图谱侧栏「成员」出现张三）
- [ ] **透明转发**：把汇总后的库再导出发给第三人 → 文件里张三的卡仍 `ownerId=张三pid`
- [ ] **重复导入幂等**：同一文件导两次 → 第二次写入 0 条（updatedAt 相同）；张三改名重导 →
      名称更新、图谱侧栏跟随
- [ ] **资料改名联动**：设置改本人名字 → 图谱成员 chips 立即用新名

## 3. G2-AUTOTAG 归档打标

- [ ] ⭐ **转变触发**：完成一张卡（写清标题/备注）→ 把系统时间调快 7 天（或改
      `completedAt` 让规则命中）→ 等每分钟规则 tick → 卡进归档 → 数秒后卡片出现 ≤3 个标签
- [ ] **守卫幂等**：已有标签的卡重复进归档不再调用（bot.log 无重复 task_autotag）
- [ ] **失败静默**：关掉机器人开关 → 完成卡让其归档 → 归档成功、无标签、无报错弹窗
      （bot.log 有 task_autotag outcome=failed 审计）
- [ ] **审计**：`$DATA/bot.log` 可 grep `task_autotag`（成功带 tags，失败带 error）
- [ ] **首屏不批量**：装有大量历史归档卡（无标签）的库启动 → **不**触发批量打标
      （bot.log 无 task_autotag 风暴）

## 4. G3-GRAPH 图谱核心

- [ ] ⭐ **导航**：左栏出现「图谱」（工作流之下），点击进入；其余栏目不变
- [ ] ⭐ **本人视图**：只有本人任务时 → 画布出现任务节点（孤立点）；工作流卡聚在
      hub 节点周围，依赖连线带箭头指向下游
- [ ] ⭐ **部门视图**：导入张三数据后 → 顶部「按成员」着色 → 本人/张三两色区分；
      成员 chips 过滤生效（只留张三 → 只剩他的子图）
- [ ] **Obsidian 交互**：hover 节点 → 邻接子图亮、其余淡出；空白拖拽平移；滚轮以
      指针为锚缩放；节点拖拽固定位置
- [ ] ⭐ **详情面板**：点节点 → 右侧显示标题/状态/归属/标签/note；本人卡有「在看板打开」
      （外来卡没有）；工作流卡有「打开工作流」
- [ ] **hub 跳转**：双击 hub → 切到工作流视图
- [ ] **过滤器**：状态三开关 / 完成年份 / 标签 / 工作流多选 / 孤立节点开关 / 重置 全部联动
      顶栏统计条（N 任务 · M 依赖 · K 工作流 · P 成员）
- [ ] **搜索**：输入关键字 → 命中节点描环；回车无需（v1 描环即可）
- [ ] **空态**：无任务 → 「暂无任务」引导；过滤器全关 → 「当前过滤器下没有节点」
- [ ] **归档在图内**：归档卡（done 色、淡化）出现在图谱，回收站卡**不**出现
