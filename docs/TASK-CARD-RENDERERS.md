## 机器人工具作用域（`bot/tools.rs active_tasks`）

所有任务操作工具（edit/complete/delete/add_subtask/toggle_subtask…）的查找域：

```
未删除 && 未归档 && column != Done
```

- **归档卡 / 已完成卡 / 回收站卡：机器人全部「找不到」**——有意设计，不是新旧不互通
- 已完成的卡再交机器人 → 工具必返回「未找到未完成任务」

## 数据流不变式

- 两套渲染器共用 `App.tsx` 传入的同一 `tasks` 数组；写入全走
  `task_patch` / `task_set_column` / `db_upsert` / `bind_files` 四条命令
- 页面间实时同步走 `bot-chat-delta` 之外的 task 变更广播（broadcast_after_mutation）
- 「今日」口径两处同源：`planStart` 日期 == 本地今天（周网格/首页任务卡）
