📋三列看板

待办 / 今日 / 完成，dnd-kit 列内排序 + 跨列拖拽，丢进完成列自动记时间。子任务、标签、备注、文件绑定 —— 该有的全都有。

📌磁吸挂件

独立透明窗口贴边隐藏，鼠标悬停滑出，📌 锁定常驻。贴顶自动变横条，位置自动记忆。双击任务标题唤起主窗口编辑。

🤖AI 机器人

挂件下方内置聊天，19 个工具：任务管理、文档润色（修订模式）、Excel 公式、PPT、PDF、本地 Python、Bing+百度搜索、流式回复。

⏰定时任务

⏰ 按钮设定时，一次 / 每天 / 每周 / 每月 四档；到点自动交给机器人执行，结果写进备注，一次性任务执行完自动清除。

🧹桌面清理

任务完成满 7 天归档后按规则自动迁移绑定文件（移动 + 更新路径）。规则表 CSV 导入导出，支持 {year} 占位符，看板中附件绝不触碰。

📚工作区收藏

主窗口「归档」与「回收站」之间的视图，按钮带 🔗 / 📄 / 📁 三类链接，标题内联编辑 + 拖拽排序；挂件只读展示可点击打开。

👤归属头像

人完成显示用户头像，机器人执行显示机器人头像。头像与姓名在设置页上传 / 修改（profile.json + 头像 base64）。

⌨️全局快捷键

唤起 / 隐藏主窗口、快速新建任务（直接进入编辑态）、切换深浅色主题 —— macOS / Windows 都有专属键位，注册失败只记日志不影响启动。

💾本地持久化

SQLite 行级增量写入，主窗口与挂件实时同步，便携模式数据库随 exe 走（U 盘即插即用）。WAL + busy_timeout 2s 保证并发安全。

看板一览

新拟态（Neumorphism）UI，圆角卡片 + 凸凹交互，长时间使用也不刺眼
