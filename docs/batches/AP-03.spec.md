# Batch Spec: AP-03

## 目的

C5-AP-03（api_handlers/ratelimit.rs:45 + :36，批内 2 处独立改动）：
1. log_line 控制字符转义不全（注释声称"全部"，实际只 \r\n\t\0——ESC/BEL/DEL/C1 可注入
   终端 escape / 伪造日志）→ 全控制字符转义（is_control() → escape_default），原有 4 个
   短形式（\\r \\n \\t \\0）保持不变。
