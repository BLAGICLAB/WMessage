# Batch Spec: SC-01

## 目的

修 scripts 域「shell 解析脆」簇：ci-guard-tiny-http-vendor.sh 两处模式未锚定（注释行 / 后缀同名目录可绕过守卫）。

## 人类可读摘要

- family: parse-fragility（shell 解析脆）
- 覆盖 findings: 3（2 实修 + 1 FP 零代码处置）
- 预估 diff: 1 file / +8/-4 lines
- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 0（OCR 命令本就 `--exclude 'scripts/**'`，本批 0 comments 为正常）

## 三条 finding 原文核实

**① ci-guard-tiny-http-vendor.sh:27（high，真）**：check #1 `grep -q 'tiny_http = { path = "vendor/tiny_http" }'` 未锚定行首——Cargo.toml 里注释掉的 `# tiny_http = { path = "vendor/tiny_http" }` 也能通过守卫。
**修法**：模式改 `'^[[:space:]]*tiny_http = { path = "vendor/tiny_http" }'`。注释行行首是 `#`（非空白），不匹配；正常行（行首 `tiny_http` 或前导空白）仍匹配。

**② ci-guard-tiny-http-vendor.sh:46（high，真）**：check #2 的 case glob `*vendor/tiny_http*` 双端不锚定——`directory+file:///x/src-tauri/vendor/tiny_http_evil` 或 `other+https://.../vendor/tiny_http/...` 也判 OK。
**修法**：模式改 `directory+file://*/src-tauri/vendor/tiny_http)`——scheme 前缀 `directory+file://` + 路径后缀 `/src-tauri/vendor/tiny_http` 双锚（`*/` 允许仓库父目录任意命名）。同步上方 :44 注释说明锚定意图。

**③ sync-version.mjs:11（high → FP，零代码处置）**：finding 声称 `^\[package\][^[]*?^version...` 会跨 `[package.metadata.bundle]` 嵌套段误捕获 version。**前提错误**：正则含字面 `\]`，且 `[^[]*?` 字符集跨不过 `[`，无法越过任何后续 section 头。已用 node 实证：构造 `[package.metadata.bundle]`（含 `version = "9.9.9"`）置于 `[package]` 段**之前**的对抗 Cargo.toml，正则仍正确捕获真 version。reviewer（agent-10）已 pass 此 FP 判定。**不进机器可读 findings 数组**。

## 验证方式说明

`bash scripts/ci-guard-tiny-http-vendor.sh` 在本机 check #2 即红（`cargo metadata --no-deps` 的 jq 提取在该环境拿不到 source，exit=1「cargo metadata 未找到 tiny_http 包」）——**与本次改动无关，是既有环境限制**。因此本批验证用对抗用例单测模式本身：

- `printf '# tiny_http = { path = "vendor/tiny_http" }\n' | grep -q '^[[:space:]]*tiny_http = { path = "vendor/tiny_http" }'` 必须失败（旧模式会通过）
- `printf 'tiny_http = { path = "vendor/tiny_http" }\n' | grep -q '^[[:space:]]*tiny_http = { path = "vendor/tiny_http" }'` 必须通过（正常行不退化）
- `SOURCE='directory+file:///x/src-tauri/vendor/tiny_http_evil'` 走新 case 必须 fail
- `SOURCE='directory+file:///any/prefix/src-tauri/vendor/tiny_http'` 走新 case 必须 OK
- `SOURCE='registry+https://github.com/rust-lang/crates.io-index'` 走新 case 必须 fail
