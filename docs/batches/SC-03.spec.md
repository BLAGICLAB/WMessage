# Batch Spec: SC-03

## 目的

修 scripts 域「set -euo 边界未封」簇：install-hooks.sh:10 的裸 glob 在目录缺失/为空时展开成字面量，`chmod` 报 No such file or directory 并使 `set -e` 中止安装——`core.hooksPath` 还没写就死了。

## 人类可读摘要

- family: glob-boundary（set -euo 边界未封）
- 覆盖 findings: 1（实修）
- 预估 diff: 1 file / +8/-1 lines
- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 0（scripts/** 被 exclude）

## finding 原文核实

**install-hooks.sh:10（high，真）**：`chmod +x .githooks/* scripts/*.sh`——无 `nullglob` 时若 `.githooks/` 或 `scripts/` 缺失/为空（partial checkout / sparse checkout / 分支无此目录），glob 字面展开，`chmod` 失败，`set -euo pipefail` 中止整个安装器。
**修法**：`shopt -s nullglob` + 数组收集 + 空数组守卫：

```bash
shopt -s nullglob
_hooks=(.githooks/*)
_scripts=(scripts/*.sh)
if [ ${#_hooks[@]} -gt 0 ]; then chmod +x "${_hooks[@]}"; fi
if [ ${#_scripts[@]} -gt 0 ]; then chmod +x "${_scripts[@]}"; fi
```

用 `if` 而非 `&&`（`[ 0 -gt 0 ] && chmod` 在 set -e 下整体返 1 会中止脚本）。

**对抗验证（已实测）**：tmp git 仓库缺 scripts/ → 旧写法报 `chmod: scripts/*.sh: No such file or directory`；新写法 exit 0；两目录全在时 chmod 正常生效（+x 位已验）。

## 修法约束

- 不改幂等语义、不改 hooksPath 写入逻辑
- 不碰同文件 :10 low（chmod 范围收窄到 allowlist）、:12 medium（.git/hooks 遮蔽警告）、:13 medium（安装后验证）——均非本簇
- nullglob 作用域是本脚本进程，不影响调用方
