# Batch Spec: SC-02

## 目的

修 scripts 域「非原子/非完整」簇：sync-version.mjs 就地写 package.json（中断即损坏）+ fetch_ocr_models.sh 截断文件被 `-s` 永久跳过、curl 退出码盲信（HTML 错误页当模型存盘）。

## 人类可读摘要

- family: atomicity/incomplete-write
- 覆盖 findings: 3（全实修）
- 预估 diff: 2 files / +25/-10 lines
- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 0（scripts/** 被 exclude）

## 三条 finding 原文核实

**① sync-version.mjs:20（high，真）**：`writeFileSync(pkgPath, ...)` 就地截断重写——中断（Ctrl+C / SIGTERM / 断电 / OOM）或盘满 → package.json 截断损坏且无备份。
**修法**：write-to-temp + rename——`writeFileSync(pkgPath + '.tmp', ...)` 后 `renameSync(tmp, pkgPath)`（POSIX/NTFS 上 rename 原子）。import 行加 `renameSync`。

**② fetch_ocr_models.sh:44（high，真）**：`-s` 只要 size>0 就跳过——网络断 / SIGINT / curl 崩造成的截断文件之后每次运行都被「已存在，跳过」，OCR 运行时加载坏 ONNX 报难诊断错误。
**修法**：下载走 `$out.partial` 临时文件，curl 成功**且通过完整性校验**后才 `mv` 就位；每次进入先 `rm -f` 旧 partial。最终文件只由原子 mv 产生，`-s` 跳过检查随之安全。

**③ fetch_ocr_models.sh:53（high，真）**：curl `-f` 只拒 4xx/5xx——200-OK 的 HTML 限流/登录/错误页会被存成「模型」，并借 `-s` 跳过永远不再拉取。
**修法**：mv 就位前校验：大小下限（ONNX ≥ 1,000,000 字节；keys.txt ≥ 10,000 字节）+ 首字节非 `<`（HTML 页判定）。不达标即删 partial、报错、return 1。下限取值依据脚本头注释标称：det 9.5MB / rec 20.2MB / cls 1.0MB / dict 75KB，下限远低于标称，不误伤真模型。

## 修法约束

- 不改 URL、不改下载源、不改跳过逻辑的对外行为（已存在好文件仍跳过）
- `set -euo pipefail` 兼容：fallback 用 `|| { ...; }` 结构，不用 `if !` 吞错误细节
- partial 残留防御：进入函数先 `rm -f "$tmp"`，失败路径也删
- 不碰 :29 medium（trap 清理——非本簇）、:32 low（DEST 校验——非本簇）、:49 high（校验和 pinning——SC-04）
