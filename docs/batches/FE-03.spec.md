## 逐条处置（原文均已核）

**实修 ① setup.ts:12-17（high）**：console.error 补丁模块加载时直赋、永不恢复；`includes("not wrapped in act")` 子串过松（任何含此子串的第三方错误都被吞）。
**修法**：改 `beforeEach` 内 `vi.spyOn(console, "error").mockImplementation`（既有 afterEach 的 `vi.restoreAllMocks()` 自动恢复，生命周期闭环）；过滤收紧为 `/not wrapped in act\(/`（必须带括号，React 19 原文 "was not wrapped in act(...)"）。

**实修 ② setup.ts:37-48（high）**：`Element.prototype.scrollTo/scrollIntoView` 模块加载期直赋原型、整轮测试存续（违反原型链安全规则）。spyOn 不可行（jsdom 根本没实现这两方法，无的可 spy）；按 suite scope 需碰 ChatPanel/WidgetApp 两测试文件且难保无隐式依赖。
**修法**：保持全局但收进显式生命周期——`beforeEach` 安装（`Object.defineProperty` configurable）、`afterEach` 仅当是本 setup 装的才 delete。不再是「模块加载直赋 + 永不恢复」。

**实修 ③ profile.ts:28-30（high）**：`force=true` 在 load 在飞时被 `if (!loading)` 吞掉——返回旧的未强制 promise，显式刷新拿到陈货。
**修法**：代际 token——`if (loading && !force) return loading`（force 无视在飞直接发新 invoke）；`loadGen` 递增，`.then` 仅 `gen === loadGen` 才写 cache + notify（旧在飞 resolve 不覆盖新结果）；`loading` 清空加 `loading === p` 身份判定。

**实修 ④ taskFiles.ts:9-10（high）**：MAX_TASK_FILES 须与 Rust db::MAX_TASK_FILES（src-tauri/src/db/tasks.rs:24 = 10）锁步，分叉静默改变 FFI 两侧截断行为。
**修法**（不开 Tauri command，零运行时面）：taskFiles.test.ts 加跨语言回归测试——fs 读 tasks.rs 正则提取 `MAX_TASK_FILES: usize = N` 与 TS 常量断言相等。

**FP ⑤ profile.ts:62-86（high → FP）**：finding 称 setters `.then` 无 `.catch` → unhandled rejection + 无用户反馈。**核后**：全部 3 个 caller（ProfileRow.tsx:44/59/78）都 `await` 在 try/catch 内 + handleCommandError + inline setError——reject 被 caller 捕获，无 unhandled；失败时 `.then` 不跑，cache/notify 本就不动。前提错误，零代码处置（reviewer 核）。

**FP ⑥ taskFiles.ts:43-44（high → FP）**：finding 称 truncated 时「UI cannot warn the user」。**核后**：两个 caller（TodoCard.tsx:130/:149）均 `if (truncated) window.alert("每个任务最多绑定 ${MAX_TASK_FILES} 个文件，超出部分已忽略")`——UI 警告已存在。前提错误，零代码处置（reviewer 核）。
