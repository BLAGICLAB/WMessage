# Batch Spec: MI-07

## 目的

C5-MI-07：migration/ops.rs log_line 的 rotation 路径与写入路径分裂（rotation 走未
canonicalize 的 `rules::log_path`，append 走 `canonicalize(data_dir)` 后的路径）——
统一为单次 canonicalize 结果，两处共用。

## 人类可读摘要

- family: 无跨域 family（单点 bug：同文件两路径来源不一致）
- 覆盖 findings: 1（C5-MI-07，ops.rs:202 区段；实际函数体在 ops.rs:252-268，行号漂移已核）
- 预估 diff: 1 file / +16/-14 lines（B 类：log_line 函数体整块重写）
- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 2

## 红线

- 不改 `log_line` 签名（`pub(crate) fn log_line(app: &AppHandle, line: &str)`，调用点 5+ 处不动）
- 不改 `println!` 开发日志通道（OCR 建议改 eprintln 属额外行为变更，不采纳）
- 不动 `rules::log_path` 本身（commands.rs:130 读侧仍在用；读侧走 syscall 级 symlink 解析，
  与写侧最终同文件，不在本批统一）
- 编译层事实必须核实，不许凭印象
