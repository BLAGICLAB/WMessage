# Batch Spec: SC-04

## 目的

修 scripts 域「第三方/CDN/用户输入未校验」簇：fetch_ocr_models.sh 模型无校验和 pinning（CDN/DNS/上游被劫持 = 静默模型替换 ≈ RCE）+ publish-docx-dotnet.sh `$1` 未校验直喂 `rm -rf`。

## 人类可读摘要

- family: untrusted-input
- 覆盖 findings: 2（全实修）
- 预估 diff: 2 files / +40/-6 lines
- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 0（scripts/** 被 exclude）
- **本批为第 50 批 → reviewer 抽查适用（每 5 批 1 次，上次第 45 批 EV-3b-G）**

## 两条 finding 原文核实

**① fetch_ocr_models.sh:49（high，真）**：模型从第三方 CDN（ModelScope → HuggingFace 回退）HTTPS 拉取，无 checksum/signature pinning，而 ONNX 被 OCR 运行时当图执行——CA 妥协 / DNS 劫持 / 上游仓库妥协 = 静默模型替换。
**修法**：仓内 `pp-ocr-v6/` 已提交好模型（脚本头注释自述「模型已随仓库提交，本脚本仅用于更新/补齐」），**以仓内文件的实测 SHA256 为 pinning 清单**嵌入脚本，下载的 partial 在 mv 就位前比对，不匹配即删 + 报错 + return 1。清单（2026-09-25 实测）：

| 文件 | SHA256 |
|---|---|
| det.onnx | 090f04abcd9d9a7498bc4ebf677e4cb9bdce1fe4197ddb7e529f1ef44e1ff94f |
| rec.onnx | 6f327246b50388f3c176ae304bd95767ea6dc0c9ae92153ef8cbe210b3c14884 |
| cls.onnx | 54379ae5174d026780215fc748a7f31910dee36818e63d49e17dc598ecc82df7 |
| keys.txt | b5f2bfe2bdd9448429e3e82b51c789775d9b42f2403d082b00662eb77e401c5d |

工具探测：`sha256sum`（Linux/Git Bash）否则 `shasum -a 256`（macOS），都无则报错退出（fail-closed，不降级跳过校验）。
**已知权衡**：上游模型若真更新，需同步更新脚本内清单——这正是 pinning 语义，脚本报错信息里写明。

**② publish-docx-dotnet.sh:12（high，真）**：`OUT_ROOT="${1:-...}"` 未校验，`OUT_DIR="$OUT_ROOT/dotnet"` 直喂 `rm -rf`——传 `/`、`..`、含 `..` 的路径或敏感位置 = 静默摧毁任意目录。
**修法**：OUT_ROOT 赋值后立即校验，拒绝：空串 / 绝对路径（`/*`）/ 含 `..`（`*..*`）/ 以 `-` 开头（防 rm 选项注入）；`rm -rf` / `mkdir -p` 加 `--` 终止选项解析。fail-closed：非法输入 exit 1 并打印用法。

## 修法约束

- fetch：不改 URL / 源 / 跳过语义；校验顺序 = 大小下限 → 首字节非 `<` → SHA256 比对 → mv
- publish：默认参数（日期戳相对路径）不受影响；校验只拦非法输入
- 不碰同文件其它 finding：fetch :29/:32；publish :11/:20/:24/:26（非本簇）

## 红线

- family 一致性：本批只含 untrusted-input
- 0 FP / 0 family 异质
- assertions_min 填 0

1. `expected_files` 覆盖全部写入路径：`scripts/fetch_ocr_models.sh` + `scripts/publish-docx-dotnet.sh`（无 ripple）✓
2. budget A 类：fetch +30/-3（清单函数 + 比对段 + 工具探测），publish +10/-3（校验段 + `--`）≈ +40/-6，上限 max +55/-15 ✓
