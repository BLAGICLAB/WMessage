# Batch Spec: WA-02

## 目的

修 WidgetApp 域「window listener 管理缺」簇：ResizeEdge Promise.all 无 catch（unhandled rejection + 拖动卡死）+ ResizeEdge / SplitBar 的 window 级 pointer 监听器在组件卸载时不清理（mid-drag unmount = 监听泄漏 + widgetDragActive 永不复位 + pointer capture 不释放）。

- family: listener-lifecycle
- 覆盖 findings: 3（全实修）
- 预估 diff: 3 files（2 改 + 1 新测试）/ +95/-12 lines
- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 3

## 三条 finding 原文核实（两文件全文已读）

**① ResizeEdge.tsx:43（high，真）**：`Promise.all([outerPosition/outerSize/scaleFactor/screenSize])` 无 `.catch`——任一 reject → startPos 永为 null，整拖静默无效 + unhandled rejection。
**修法**：`.catch` 分支 console.warn 记录；startPos 保持 null（move 忽略），pointerup 时 cleanup 正常复位——拖动可恢复，不卡死。

**② ResizeEdge.tsx:72（high，真）**：pointermove/pointerup/pointercancel 同步挂在 window 上，无 useEffect 卸载清理——mid-drag unmount → 监听永驻、pointer capture 不释放、`setWidgetDragActive(true)` 永不复位。
**修法**：`dragCleanupRef = useRef<(() => void) | null>(null)` + `useEffect(() => () => dragCleanupRef.current?.(), [])`；cleanup 签名改 `(ev?: PointerEvent)`（无 ev 跳过 releasePointerCapture），onDown 注册监听后 `dragCleanupRef.current = () => cleanup()`，cleanup 内复位 ref。

**③ SplitBar.tsx:15（high，真）**：同 ② 同根因同形态。
**修法**：同 ② 同款 ref + useEffect 卸载清理。

## 测试（新文件 src/components/WidgetApp/drag-cleanup.test.tsx）

vitest + jsdom + @testing-library/react（既有基建），mock `@tauri-apps/api/window`（getCurrentWindow 三异步方法 + currentMonitor）：
- ResizeEdge：pointerdown → unmount（mid-drag）→ widgetDragActive 复位 false + 之后 pointermove 不再调 onDelta
- ResizeEdge：正常拖动路径不退化——pointerdown → pointermove 调 onDelta → pointerup 后 move 不再调
- SplitBar：pointerdown（非 button 目标）→ unmount → widgetDragActive 复位 + onSplit 不再调
- SplitBar：onPointerDown 落在 button 上时不起拖（既有行为保留）
