## 修法

- `days_elapsed` 计算改 `now_ms.saturating_sub(start_ms)`（溢出饱和到
  i64::MAX → days 巨大 → FourteenDaysElapsed 响，不再静默归零）；
- `now_ms < start_ms` 时 eprintln! `[evolution_stop]` warn（负时长 =
  配置/时钟异常，留痕不静默），days_elapsed 仍 0.0（不误触发时间门）；
- 新增测试 2 个：负时长 → days_elapsed==0.0 + 不因时间门停 + 不 panic；
  溢出（start_ms=i64::MIN）→ 饱和 → FourteenDaysElapsed 触发。
