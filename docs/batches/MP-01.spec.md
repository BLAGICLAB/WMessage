# Batch Spec: MP-01

## 目的

产品变更（用户拍板 2026-09-26）：聊天区/挂件头部 🧠 模型标签从只读 span 升级为与 🤖 会话切换器同款下拉——点击弹当前协议模型列表，选中即写配置 + 广播同步。原标签为设计如此（ChatPanel.tsx:996 注释「只读；模型在设置页维护」），本批推翻该交互。

## 人类可读摘要

- family: fe-model-picker
- 覆盖: 后端窄口径命令 1 个 + 前端下拉 UI + 双端测试
- 预估 diff: 7 文件 / +315/-20（spec 校正 ×1：补列 bot.rs/config/mod.rs 两处再导出与测试宿主）
- OCR 计划: 跳过（纯 UI/配置面批，无数据/安全/权限面；gate+测试担保）

## 设计（关键取舍）

**写路径走后端窄口径，不走前端整份写回**：设置页 saveConfig 是「整份 config 对象写回」，ChatPanel 若复制该路径，用打开菜单时的旧快照写回会覆盖设置页并发修改（allowedDirs/开关等）——字段漂移隐患。故新增 `bot_set_active_model`：读盘上最新配置（单一事实源）→ 只动当前协议 active_model_id → 复用 `derive_legacy_fields_from_active` 派生老字段 → 落盘 → 返回新 BotConfigView。

## 逐条处置

**① 后端 commands.rs**：新命令 `bot_set_active_model(app, model_id)`：
`io::load_config` → `schema::migrate_legacy_models`（老配置内存补列表，id 稳定 "migrated"）→
纯函数 `apply_active_model_switch`（校验 id 存在于当前协议列表，不存在 → InvalidArgument 响亮失败）→
`derive_legacy_fields_from_active` → `io::write_bot_config_file` → 返回 `bot_get_config` view。
ripple：无既有签名变动；lib.rs generate_handler 注册一行。

**② 前端 ChatPanel.tsx**：
- 🧠 span → button（▴/▾ 指示符同 🤖），title「切换模型」。
- 挂载/bot-config-changed 的 reload 扩展：`bot_get_config` 返回里取当前 apiProvider 协议的
  models 列表 + activeModelId，一并 set。
- 下拉：绝对定位 right-0（复用 rootRef 相对容器 + btn 底沿测量，模式同会话菜单），
  列表项 = label，active 高亮；空列表显示提示行「模型列表为空，去设置页添加」。
- 选中：`invoke("bot_set_active_model", { modelId })` → 用返回 view 更新 label/activeId →
  `emit("bot-config-changed")`（另一窗口的 ChatPanel 实例靠既有 listener 刷新）→ 关菜单。
  失败：`handleCommandError(e, "切换模型")`（非 silent，用户主动操作）。
- 外点关闭：镜像会话菜单的 mousedown-outside effect（chip + 下拉双 ref 检测）。

**③ ChatPanel/types.ts**：新增 `ChatModelEntry { id, label, model }`（不 import SettingsPage
types——该文件头部注明外部不直接引用）。

**④ 测试**：
- Rust：commands.rs 新增 #[cfg(test)]（纯函数三态——列表空 Err / id 命中置 active+派生 /
  跨协议 id Err）。
- 前端：ChatPanel.test.tsx 补 bot_get_config/bot_set_active_model mock case；新增 2 用例——
  点 🧠 弹列表并展示条目 / 点条目调用 bot_set_active_model 且 label 刷新。

## 红线

- 不动 bot_set_config / saveConfig 既有路径；不动 derive_legacy_fields_from_active 语义
- key 永不经由新命令读写（凭据存储路径不触碰）
- 挂件/主窗口共用 ChatPanel，行为一致，不特判挂件
