# Batch Spec: FE-05

## 目的

修 frontend 域「UI 控件」簇（C5-FE-05）：ProfileRow setTimeout 无清理 + busy 时输入框可编辑（数据丢失路径）+ FoldToggle type/aria 状态 + RichText 锚点无 href + Fold 折叠状态不可达。6 条全实修。

- OCR 计划: r1, timeout 1800s, 期望 comments ≤ 6

## 逐条处置（原文均已核）

**实修 ① ProfileRow.tsx:78-81（high）**：`setTimeout(() => setSaved(false), 1500)` 不存句柄无清理——卸载后触发 setState、重复保存计时器叠加。
**修法**：`savedTimer = useRef<ReturnType<typeof setTimeout> | null>(null)`；saveName 里先 clear 旧计时再设新；`useEffect(() => () => clearTimeout, [])` 卸载清理。

**实修 ② ProfileRow.tsx:110-118（high）**：busy 时 input 仍可编辑——保存 await 期间继续输入，`setDirty(false)` 触发 `useEffect([entry, dirty])` 用旧值覆盖新击键（数据丢失）。
**修法**：input 加 `disabled={busy}`（保存在飞期间禁止输入，从源头关闭竞态）。

**实修 ③ FoldToggle.tsx:15-16（high）**：`<button>` 无 type，form 内默认 submit。
**修法**：`type="button"`。

**实修 ④ FoldToggle.tsx:21（high）**：折叠开关无可达状态（title 不是可靠 accessible name）。
**修法**：`aria-expanded={!collapsed}` + `aria-label={collapsed ? "展开" : "收起"}`。aria-controls 不加——被控内容在父组件（TodoCard/TaskCardContent/WorkspacePage），穿 id 属扩 scope。

**实修 ⑤ RichText.tsx:22-32（high）**：`<a>` 无 href——不可 Tab 聚焦、中键/右键无效、屏幕阅读器不播报。
**修法**：与 FE-04 MarkdownText 同形态——URL 给 `href={clean}`；路径不设 href，补 `role="link"` + `tabIndex={0}` + Enter 键触发 openTarget。

**实修 ⑥ Fold.tsx:16-19（high，合并同命中 medium type 缺失）**：折叠按钮状态仅视觉 glyph；且无 type。
**修法**：`type="button"` + `aria-expanded={open}` + `useId()` 产 id，`aria-controls={id}` + 面板 `<div id={id}>`（Fold 自拥面板，可闭合 aria-controls）。
