## 逐条处置（原文均已核）

**实修 ① SkillsPanel.tsx:60-63（high）**：`setTimeout(() => setNotice(""), 3000)` 无句柄——卸载后 setState + 3s 内二次导入新 notice 被旧计时器提前清掉。
**修法**：noticeTimer ref（同 FE-05 ProfileRow 形态）：设定前 clear 旧的 + 卸载 useEffect 清理。

**实修 ② ApiProviderSelect.tsx:37-41（high）**：自绘下拉零 WAI-ARIA——无 aria-haspopup/aria-expanded/listbox/option/aria-selected，键盘仅 Escape，无方向键/Home/End/Enter。
**修法**：触发钮 `aria-haspopup="listbox"` + `aria-expanded={open}`；浮层 `role="listbox"` + `aria-activedescendant`；选项 `role="option"` + `aria-selected` + id；activeIdx state（open 时对齐当前值）+ 方向键/Home/End 移动 + Enter/Space 提交 + active 项视觉高亮。点击行为不变。

**实修 ③ DeleteConfirmDialog.tsx:40-46（high，合并同命中 low backdrop）**：aria-modal=true 但无焦点移入/恢复/trap——键盘可 Tab 到遮罩后页面。
**修法**：挂载时焦点移入弹窗（默认落「取消」钮——破坏性确认的安全默认）+ 卸载恢复焦点到原触发元素；backdrop 点击 = onCancel（busy 时忽略，与 Esc 一致；取消是无害路径）+ 内卡 stopPropagation。focus trap 不实现（弹窗仅两钮一 checkbox，Tab 循环价值低），注释声明。

**实修 ⑤ ActorAvatar.tsx:10-12（high）**：`loadProfile().then(...)` 无 catch——reject 成 unhandled rejection，静默滞留旧缓存。
**修法**：`.catch` console.error 留痕（保持当前缓存兜底，不弹窗——头像/姓名非关键路径）。

**实修 ⑥ ArchivePage.tsx:52-55（high）**：displayTask 对已折叠（collapsed===true）且非编辑目标的卡片每渲染产新对象，破坏引用相等（memo 失效）。
**修法**：仅当值真正翻转（collapsed===undefined）才分配副本；collapsed===true 直接复用引用。

**转 B 类 ④ EvolutionPanel/types.ts:24-28（high → B 类 #23）**：ProposalTarget union 暴露 snake_case 字段（tool_name/skill_name/policy），response 路径 verbatim 自 serde，camelCase 习惯的 consumer 写 toolName 会静默 undefined 但编译过。**方向抉择**：A=字段 camelCase 重命名（serde rename + 全部消费方面改 = 跨域签名改，扩 scope）；B=类型注释文档化 verbatim 契约（字段级 JSDoc 声明来自 serde response）；C=wontfix。扩 scope 触 B 类红线，攒批报人拍。
