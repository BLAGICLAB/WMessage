# 任务卡三渲染器功能矩阵（2026-10-14）

> 逐字段核对三套任务卡渲染器的真实行为（从代码核对，非文档转述）。
> 用途：改任何一套卡片前先查此表，确认「其他两套要不要同步」；
> 新增 Task 字段时在此登记三套的显示/编辑口径。
> 数据层唯一事实：`tasks` 表 + `Task` 类型（src/types.ts:64）——三套渲染器

## 机器人工具作用域（`bot/tools.rs active_tasks`）

所有任务操作工具（edit/complete/delete/add_subtask/toggle_subtask…）的查找域：

```
未删除 && 未归档 && column != Done
```

- **归档卡 / 已完成卡 / 回收站卡：机器人全部「找不到」**——有意设计，不是新旧不互通
- 挂件「交给机器人」执行时卡仍在域内 → 可正常 complete/delete（delete 弹确认）
- 已完成的卡再交机器人 → 工具必返回「未找到未完成任务」（见待拍板①）

## 数据流不变式

- 三套渲染器共用 `App.tsx` 传入的同一 `tasks` 数组；写入全走
  `task_patch` / `task_set_column` / `db_upsert` / `bind_files` 四条命令
- 挂件与主窗口实时同步走 `bot-chat-delta` 之外的 task 变更广播（broadcast_after_mutation）
- 「今日」口径三处同源：`planStart` 日期 == 本地今天（挂件/周网格/首页任务卡）
